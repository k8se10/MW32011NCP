# Documentation

**This is an IW5-only fork** (see the [root README](../README.md) for
why) — the docs in this folder, inherited from upstream OpenAssetTools,
still describe the full multi-game project. Treat anything not related to
IW5 as unmaintained reference, not something this fork is actively
keeping current.

Upstream's own hosted documentation: [https://openassettools.dev](https://openassettools.dev/).
Its source: [OAT Docs Repository](https://github.com/OpenAssetTools/Docs)
(not part of this fork).

This project's own IW5 x64 root-cause research and plan lives outside
this directory, in the parent project:
[`re_notes/x64_migration/fastfile_format_research.md`](../../../re_notes/x64_migration/fastfile_format_research.md).
