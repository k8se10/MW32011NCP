[b]v0.0.3-x64[/b] (2026-09-27) — The biggest release yet. Native Vulkan rendering is now the default in Campaign/Survival (bundled DXVK fork), with opt-in NVIDIA DLSS/DLAA for RTX GPUs working end to end, including above 100% render scale. Major performance fixes, all on by default: "the 67 bug" (Dome at 250% render scale went from 23 to a 76 fps average, and the pause menu now runs faster than gameplay) plus four other redundant-work skips from Activision's 64-bit recompile. The "everything sounds like it's in a small room" reverb bug is fixed. Multiplayer gets controller menu navigation and the performance fixes (no in-game MP controller support yet). [color=#e5c07b]A one-week development break starts on release day (to 2026-10-04); v0.0.3-x64 is the LTS candidate for this line.[/color]

[b]v0.0.2-x64[/b] (2026-09-23) — Internal render scale now works in Multiplayer (on by default, no VAC-risk opt-in needed); fixed a critical MP launch crash and root-caused the render-scale stutter to a genuine native engine limit (not a mod bug) — [color=#e5c07b]confirmed the safe threshold is content-dependent, not one fixed percentage: the same 200% that's clean in SP causes constant lag in MP[/color]. Motion blur is no longer controller-only. New RE groundwork: a first map of the native renderer's architecture (shadow maps and the full render-target table found) and a previously-undocumented native SSAO implementation. Corrected a real doc bug: the forced anisotropic/shadow/lighting toggles have been silent no-ops on x64 since the port.

[b]v0.0.1-x64[/b] (2026-09-22) — First release on the -x64 line, rebuilding from scratch against MW3's recompiled 64-bit binaries, now also folding in netcode security patching (all 4 tracked vulnerabilities fixed). Survival's controller support is Gameplay Complete (2026-09-22) — every core control confirmed live, including Predator Missile guidance, ready-up/buy-station prompts, D-pad, and the visual-enhancement suite's headline features. One cosmetic bug remains (Back glyph flicker); sentry/QTE prompt text, the Custom Options screen's vanilla tabs, AC-130 gun switching, and SMAA remain genuinely open.
