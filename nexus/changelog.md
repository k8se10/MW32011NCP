## v0.0.1-x64 — Unreleased

The first release on the `-x64` line, rebuilding this project from scratch
against MW3's recompiled 64-bit binaries. Every core gameplay control is
implemented and build-verified, most confirmed live: analog movement/look,
Sprint, Fire, true hold-to-aim ADS, Reload, weapon switch, Melee, Lethal,
Tactical, Jump, Interact, the full Crouch/Prone stance ladder, and pause menu
open/close. The plugin API is ported, and the custom Options screen is wired
in (temporary open method). Not yet on this line: controller-glyph icons,
on-screen hint prompts, the custom cursor, and the visual-enhancement suite
that shipped on the prior 32-bit line. **This release has not shipped.**

The prior `-x86` line's full changelog history is preserved in this project's
GitHub repository under `legacy-x86-docs/nexus/changelog.bbcode.txt`.
