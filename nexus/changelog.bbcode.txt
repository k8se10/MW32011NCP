[b][size=4]v0.3.3 — Alpha (2026-08-18) — Real, extended-session performance stuttering fixed[/size][/b]

[color=#E74C3C][b]Headline fix:[/b][/color] real, extended-session performance stuttering — three separate, evidence-backed causes found and fixed. [font=Courier New]proxy_d3d9.log[/font] was opened in append mode and never trimmed between launches (grew past 2GB across every session since install). The background controller-poll thread never stopped rescanning every XInput slot plus DualSense on every ~4ms tick, even once the active device was known — now locks onto the active device once at boot. A diagnostic log's dedup logic didn't actually deduplicate, producing hundreds of thousands of lines in a single combat session. A/B tested directly against v0.2.2 to confirm the regression was real, not imagined — user-confirmed "much better" afterward. One residual dip (looking toward enemies) remains open, most likely genuine GPU-side rendering cost — see [font=Courier New]re_notes/known_issues.md[/font] issue #79.

[b]Also fixed:[/b] vibration could get stuck on indefinitely across a pause or menu. A real co-op bug where damage-taken rumble could trigger off a teammate's hits instead of your own — mitigated (disables itself when a second real player is detected) pending further research into the real "which player is me" mechanism.

[color=#E74C3C][b]Ships a first, PREVIEW/WIP pass at DualSense Bluetooth support — stick input does not work correctly over Bluetooth, confirmed live against real hardware; do not rely on it for gameplay.[/b][/color] USB DualSense support (added v0.3.2) still hasn't been independently confirmed working either — see issue #76.

[b][size=4]v0.3.2 — Alpha (2026-08-16) — Controller-glyph icons actually work now; native DualSense/gyro preview[/size][/b]

[color=#E74C3C][b]Headline fix, and worth being blunt about:[/b][/color] every "no controller glyphs" report this mod has ever received, going all the way back to v0.3.0, traced to one cause — this project's own master on/off switch for the whole glyph overlay was hardcoded off and never flipped on for release. Not a hardware quirk, not Steam Overlay, not a memory-address theory — this mod shipped its own headline feature permanently disabled by mistake, three releases in a row. Finding that took 16 days and two full investigation rounds, including two real-but-partial fixes along the way and two externally-sourced theories that both turned out to be unnecessary, because nobody re-checked this project's own simplest config flag against a log line that had been printing the answer the entire time. If controller glyphs never worked for you on ANY prior release, this is why — fixed and confirmed live via direct reproduction, not assumed. The flag itself was removed entirely (not just re-defaulted) so upgrading from an older install can't get silently stuck on the old broken value. [b]Also new, PREVIEW/WIP, off by default:[/b] a first pass at native DualSense (PS5 controller) support via raw HID, bypassing Steam Input entirely, plus native gyro-aim riding the same connection — not yet live-tested against real hardware. Full detail on GitHub: see this mod's Source page, [font=Courier New]PATCHNOTES.md[/font] and [font=Courier New]re_notes/known_issues.md[/font] issues #74 (full incident postmortem) and #76.

[b][size=4]v0.2.2 — Alpha (2026-07-20) — Risk-mitigation release[/size][/b]

[color=#F39C12]⚠ Recommended update for anyone on v0.2.1 or earlier.[/color] [b]Aim assist has been permanently removed[/b] — not just disabled, the code is deleted entirely. Deep anti-cheat research found the closest real precedent for a proxy-DLL project that reads/manipulates gameplay memory beyond pure input remapping (ENB) has actual documented ban history, unlike this project's core input-remapping work, which is architecturally closer to ReShade's clean track record (never reads gameplay memory, only writes real values into real input structures). Whether earlier builds' mere presence of aim-assist code raised VAC exposure is not confirmed — no ban has been reported — but is genuinely suspected enough to warrant this release. No other player-facing changes.
