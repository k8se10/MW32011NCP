# Legacy `-x86` documentation archive

Everything under this folder is the final, frozen state of this project's
documentation as of the `-x86` line's discontinuation (2026-09-03) — moved
here wholesale rather than deleted so it stays easy to browse and reference
directly, alongside the same information's permanent record in git history.

**This is a historical snapshot, not maintained going forward.** The live
docs at the repo root (`README.md`, `CONTRIBUTING.md`, `CODE_STANDARDS.md`,
etc.) describe the current, actively-developed `-x64` line. If something
here conflicts with a live doc, the live doc is correct — this folder exists
for reference (structure, tables, ideas, historical context) while writing
the fresh `-x64` documentation, not as a second source of truth.

`wiki/` holds a plain copy of the GitHub wiki's own final `-x86`-era pages
(`k8se10/MW32011NCP.wiki.git`, synced through commit `29a3eec`) — the wiki
itself is a separate repository with its own git history; this is a
convenience mirror, not the source of record for that repo.
